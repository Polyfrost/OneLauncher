# Clusters can import modpacks

It works by importing from a file as well as importing from the browser.
You can add it by going into the browser, then modpacks and clicking "Add to an Instance".
You can also add it by going into the cluster settings, scrolling down, and clicking browse on the modpack row.

# Bad modpacks support

Now modpacks can be flagged and provide an explanation for flagging.
